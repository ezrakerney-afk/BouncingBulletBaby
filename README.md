# Bouncing Bullet Baby

A wild west ricochet puzzle game made for a game jam.

You're a baby with a revolver. Bullets bounce off walls, so bank your shots around the room to hit every target. Clear a level without wasting a bullet for a Perfect. Ten levels.

## Controls

- Mouse: aim, left click to shoot
- R: restart the level
- Esc: back to the menu

## Building

Unity 6000.6.9f1. Run **Bouncing Bullet Baby > Build Levels** once to generate the scenes. Levels are text maps in `Assets/Levels`, and `python3 tools/levels.py` checks they're all beatable.
